## 🎨 Overview

## 🚀 Key Features & Pages

- **Home (`index.html`)**: Complete studio overview, portfolio preview, client trust signals, testimonials, and interactive 3D character engine.
- **Services (`services.html`)**: Catalog of 6 core services and comprehensive sub-services:
  1. Branding & Visual Identity
  2. Graphic & Communication Design
  3. Web & Digital Design
  4. Motion Graphics & Video
  5. Packaging & Print Design
  6. Creative Direction
- **Company Portfolio (`portfolio.html`)**: Commercial showcase of client projects across branding, web design, UI/UX, and marketing creatives.
- **Team Portfolio (`team-portfolio.html`)**: Personal resume, career timeline (6 leadership roles), and visual design portfolio of Creative Director **Priyanshu Singh**.
- **About Us (`about.html`)**: Studio philosophy, creative direction principles, and methodology.
- **Interactive Pricing Engine (`payment.html`)**: Per-service live price customizer across 3 core packages:
  - Social Media & Ad Creatives
  - Website & Digital Design
  - Branding & Packaging Design
  *(Dynamic checkbox calculation, GST 18%, 50% advance estimate, and direct booking flow).*
- **Contact (`contact.html`)**: Self-contained inquiry form with dual-API synchronization (Web3Forms & Google Sheets) and an animated Thank You popup modal.

## ⚡ Tech Stack

- **Frontend**: Semantic HTML5, Modern CSS3 (CSS Variables, Flexbox, Grid, Glassmorphism), Vanilla JavaScript (ES6+).
- **3D Interactive Engine**: [Spline.design](https://spline.design/) — embedded via `@splinetool/viewer` custom element.
- **Typography**: [Manrope](https://fonts.google.com/specimen/Manrope) (Google Fonts).
- **Icons**: [Font Awesome 6](https://fontawesome.com/).
- **Form Endpoints**:
  - **Web3Forms**: Access key integration for real-time inquiry email delivery.
  - **Google Apps Script**: Direct JSON sync to Google Sheets CRM pipeline.
- **Hosting**: [Hostinger](https://www.hostinger.in/) — static files deployed to `public_html` via GitHub.
- **Server Config**: Apache `.htaccess` — clean URLs, HTTPS redirect, browser caching & Gzip compression.
